# 株式会社ロックハーツ

福岡・大阪など西日本エリアを中心に、業界トップクラス**20,000本以上**の制作実績を持つ動画&WEBマーケティング会社です。
「動画制作・映像制作」と「デジタルマーケティング」の両軸で、コストパフォーマンスの高いクリエイティブを提供します。

[公式サイト](https://rockhearts.co.jp/) | [採用サイト](https://rockhearts.co.jp/recruit)

---

## 事業内容 (Business Domains)

### 映像制作事業

企画・構成から撮影・編集までワンストップで制作。

- **広告・ブランディング**: 企業PV、TVCM、SNS広告動画
- **採用・リクルート**: 企業の魅力を伝える採用ムービー
- **ウェディング**: 一生に一度の瞬間を彩る映像演出
- **実績**: 20,000本以上の制作実績

### デジタルマーケティング事業

- **Webサイト制作**: コーポレートサイト、ECサイト構築
- **広告運用**: リスティング、SNS広告の企画・運用
- **クリエイティブ制作**: バナー、LP制作
- **コンサルティング**: SEO、SNS運用支援
